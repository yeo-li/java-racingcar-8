## 핵심 기능

---

### ☑️ 경주 자동차 입력 기능

- 사용자에게 경주할 자동차 이름을 입력 받는다.
- 입력값의 공백을 모두 제거해야 한다.
- 자동차 이름은 쉼표(,) 기준으로 구분한다.

### ⚠️ 기능 예외 사항

- 입력값에 공백만 들어있으면 예외를 발생 시켜야 한다.
- 자동차 이름이 5자 초과라면 예외를 발생 시켜야 한다.
- 자동차 이름이 공백만 있다면 예외를 발생 시켜야 한다.
- 자동차의 수가 10대를 넘어가면 예외를 발생 시켜야 한다.

---

### ☑️ 시도 횟수 입력 기능

- 경주를 몇 번 할지 사용자에게 입력 받는다.
- 입력값의 공백을 모두 제거해야 한다.

### ⚠️ 기능 예외 사항

- 입력값에 공백만 들어있으면 예외를 발생 시켜야 한다.
- 입력값이 숫자가 아니라면 예외를 발생 시켜야 한다.
- 입력값이 1000을 초과하면 예외를 발생 시켜야 한다.

---

### ☑️ 경주 기능

- 모든 자동차를 랜덤으로 전진시킨다.
- 경주의 결과는 저장 되어야 한다.

---

### ☑️ 최종 우승자 판단 기능

- 우승자는 최소 1명 최대 10명이다.
- 가장 많이 앞으로 전진한 자동차들이 최종 우승이다.
