# java-racingcar-precourse

---

## 1. 입력

### ✅ 자동차 이름 입력 기능

```text
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
```

---

### ✅ 시도 횟수 입력 기능

- 사용자로부터 경주 **시도 횟수**를 문자열로 입력 받음

```text
시도할 횟수는 몇 회인가요?
5
```

---

## 2. 출력

### ☑️ 차수별 실행 결과 출력 기능

- 각 시도마다 자동차의 진행 상황을 출력

```text
pobi : --
woni : ----
jun : ---
```

---

### ☑️ 최종 우승자 출력 기능

- 가장 멀리 간 자동차(들)를 출력

**단독 우승자**

```text
최종 우승자 : pobi
```

**공동 우승자**

```text
최종 우승자 : pobi, jun
```

---

## 3. 핵심 기능

### ✅ 자동차 등록 기능

- 사용자로부터 입력받은 이름들을 기반으로 자동차 객체(`RacingCar`) 생성 및 List<RacingCar>로 반환
- 자동차 이름은 쉼표(`,`)로 구분하여 입력
- 입력값의 공백은 모두 제거 후 판별
- 이름은 최대 5자 이하만 가능
- 중복된 이름은 입력 불가
- 자동차 이름은 영어만 가능(대소문자 구분 가능)

### ⚠️ 기능 예외 상황

- 자동차 이름이 5자를 초과하는 경우
- 자동차 이름에 중복이 있는 경우
- 자동차 이름이 ""인 경우(예시: ",,,")
- "", " " 처럼 공백을 입력한 경우(자동차를 한 대도 입력하지 않은 경우)
- 알파벳, ","과 공백을 제외한 다른 문자가 들어온 경우

---

### ☑️ 시도 횟수 저장 기능

- 사용자로부터 입력받은 횟수를 저장하여 경주에 반영
- 입력 값은 0 이상 10,000 이하의 정수

### ⚠️ 기능 예외 상황

- 시도 횟수 입력값에 숫자를 제외한 다른 값이 있는 경우
- 입력 값이 0 미만 10,000 초과의 정수인 경우

---

### ✅ 자동차 전진 기능

- 각 자동차는 매 시도마다 0-9 사이의 난수 생성
- 생성된 숫자가 4 이상일 경우 한 칸 전진

### ⚠️ 기능 예외 상황

- 전진 로직과 관련된 별도의 예외는 없음

---

### ☑️ 자동차 경주 기능

- 시도 횟수만큼 반복하여 자동차들을 순차적으로 전진시킴

### ⚠️ 기능 예외 상황

---

### ☑️ 자동차 경주 결과 계산 기능

- 각 자동차들의 전진 거리를 바탕으로 가장 멀리 간 자동차(들)를 반환
